열쇠 발급 방법 (처음 한 번만)
  1. 깃허브 로그인 후 토큰 발급 화면을 엽니다.
  2. Token name 에 eplant-voca 라고 적습니다.
  3. Expiration 은 1 year 를 고릅니다.
  4. Repository access 에서 Only select repositories 를 고르고 eplant 를 고릅니다.
  5. Permissions → Repository permissions → Contents 를 Read and write 로 바꿉니다. 나머지는 그대로 둡니다.
  6. 맨 아래 Generate token 을 누르고 나온 값을 복사해 위 칸에 붙여넣습니다.
이 값은 화면을 벗어나면 다시 볼 수 없습니다. 메모장에 따로 보관해 두십시오.
만료되면 같은 절차로 새로 받아 붙여넣으면 됩니다.
